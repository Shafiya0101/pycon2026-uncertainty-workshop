# Metacognitive Uncertainty Layer (Streamlit)

Interactive demo for the PyCon ES 2026 workshop *Detecting LLM Hallucinations with Uncertainty
Fingerprinting*. Lightweight version: 3 study settings (Mistral-7B and Qwen2-7B on TriviaQA,
Mistral-7B on Natural Questions), no neural network at runtime.

Run locally: `pip install -r requirements.txt` then `streamlit run streamlit_app.py`.
